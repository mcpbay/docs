# mcpb install-mcp

Installs the MCPB MCP server to an AI tool.

## Syntax

```sh
mcpb install-mcp [options] <target>
```

## Arguments

### options

#### --mcp-name \<name\>

Defines a name for the MCP.

#### --scope \<scope\>

Defines the installation scope: `project`, `global`, and `user`.

##### name

The name of the MCP server.

### target

- claudecode
- opencode
- cursor
